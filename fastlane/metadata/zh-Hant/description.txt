Slochetok 是教練與治療師用的會談筆記簿。你在本機保存客戶名冊，每次到訪以 0 到 10 的量表進行，寫下結果、方法與行動，再覆核以歸檔筆記。

• 會談筆記留在這部手機上
• 客戶名冊含姓名與台號
• 用面容 ID 啟封客戶
• 在縱向 0–10 量表滑珠上打開到訪
• 寫下結果，然後設定
• 寫下方法與行動，然後收穫
• 蓋上信心 1–5 並覆核以歸檔本次到訪
• 覆核後自動打開下一空白到訪
• 撤回可在下一到訪仍為空白時拿掉最近歸檔的筆記
• 所選客戶的進度量表條與已歸檔信心列表
• 掃描台號二維碼，或輸入台號，以打開該次到訪
• 匯出到訪 JSON
• 再次執行引導
• 重置全部資料
• 聯絡 Stile

姓名、到訪與筆記留在本機。
