Slochetok 是面向教练与治疗师的会谈笔记簿。你在本机保存客户名册，每次到访在 0 到 10 的量表上进行，写下结果、方法与行动，再复核以归档笔记。

• 会谈笔记留在这部手机上
• 客户名册含姓名与台号
• 用面容 ID 启封客户
• 在纵向 0–10 量表滑珠上打开到访
• 写下结果，然后设定
• 写下方法与行动，然后收获
• 盖上信心 1–5 并复核以归档本次到访
• 复核后自动打开下一空白到访
• 撤回可在下一到访仍为空白时去掉最近归档的笔记
• 所选客户的进度量表条与已归档信心列表
• 扫描台号二维码，或输入台号，以打开对应到访
• 导出到访 JSON
• 再次运行引导
• 重置全部数据
• 联系 Stile

姓名、到访与笔记留在本机。
